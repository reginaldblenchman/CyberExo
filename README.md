# *CyberExo*

The CyberExo project is a modular net of devices that aims at making life easier.

### About Modules:
1. HUD glasses,
2. Heartbeat sensor,
3. Sensor pack (temperature, pressure, etc.),
4. Gyro wristband,
And more

### Types:
1. **CyberExo Mobile**  
   Not modular compact HUD glasses, that combine everything needed in one. Featuring:
   * 500mAh battery,
   * MCU equipped with bluetooth and WiFi,
   * 2 Transparent OLED displays in the lenses,
   * 3D printed frame.
   
   Those glasses can display text like current time or notifications from a smartphone. They will be much cheaper than the alternatives.

2. **CyberExo Modular**  
   Modular version of the system, which has a main unit that connects to other modules by a common CAN line. Features:
   * Main unit,
   * Bigger battery,
   * Magnetic connectors suitable for hotswapping modules,
   * Main CAN line that allows for connecting up to 6 modules at once,
   * Bluetooth and WiFi connectivity.
   
   The main unit is going to be in a form of a wearable board located on back/neck. Cables used for communication and powering other modules are going to be routed parallel to the user's hands. The Modular version will be able to connect to the Mobile version and work together. Modules do not require any batteries, power and communication is going to be supported with one cable with magnetic pogo pin connectors.
